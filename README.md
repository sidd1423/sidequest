# sidequest

A Python project built with [Streamlit](https://streamlit.io).

## Setup (Windows PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add any secrets there (`.env` is git-ignored).

## Run

```powershell
streamlit run app.py
```
